# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. Email: security@cixio.online
3. Include: description, steps to reproduce, potential impact

## Security Measures

This organization uses:
- SAML SSO with MFA enforcement
- IP allowlist (access restricted to approved IPs only)
- Dependabot for dependency vulnerability scanning
- Secret scanning with push protection
- Branch protection on all default branches
- Code review required for all merges

## Supported Versions

Only the latest version of each repository is actively maintained.
