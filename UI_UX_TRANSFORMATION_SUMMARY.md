## 🚀 Quick Start

### View the Site

1. **Install dependencies** (if not already done):
   ```bash
   npm install
   ```

2. **Start the server**:
   ```bash
   npm start
   ```

3. **View in browser**:
   - Main site: `http://localhost:3000`
   - Demo page: `http://localhost:3000/demo.html`

### Or Use Simple HTTP Server

```bash
cd public
python3 -m http.server 8080
# Open http://localhost:8080
```
