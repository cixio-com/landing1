CIXIO LLM — Self-Hosted LLM Gateway

OpenAI-compatible unified LLM gateway that routes API requests to any backend — Ollama, vLLM, llama.cpp, or HuggingFace — with zero data leaving your infrastructure. Single API endpoint for 25+ curated models with streaming, token counting, and rate limiting.

  • OpenAI-Compatible API (/v1/chat/completions)
  • 25+ Models — Ollama, vLLM, HuggingFace
  • Streaming SSE + Token Counting
  • Enterprise: RBAC, SSO, PII Redaction, Billing
  • Docker CPU & GPU (CUDA 12.4) Deployment

CIXIO Code — Privacy-First Code Editor

A production-ready code editor forked from VS Code (Code-OSS) with zero telemetry, zero external API calls, and pre-configured local AI integration via CIXIO LLM. Full extension support via Open VSX. Ships v1.113.0 for macOS, Windows, and Linux with Docker deployment.

  • VS Code Fork — Zero Telemetry & Zero Tracking
  • Local AI Coding Assistant (via CIXIO LLM)
  • Open VSX Extension Marketplace
  • macOS, Windows, Linux + Docker
  • Version 1.113.0 — Production-Ready

CIXIO Browser — De-Googled Enterprise Browser

A privacy-first desktop browser built on Electron/Chromium with 25+ tracking features disabled, zero third-party telemetry, enterprise policy management, activity monitoring, URL blocklists, and full CIXIO SSO integration. Distributed as platform-native installers (DMG, EXE, AppImage).

  • 25+ Tracking & Telemetry Features Disabled
  • Enterprise Policy & URL Blocklists
  • Activity Monitoring & Audit Logs
  • Built-In SSO & Zero-Trust Auth
  • macOS (DMG), Windows (EXE), Linux (AppImage)

CIXIO PASS — Encrypted Document Vault

Military-grade encrypted document wallet for identity documents (passports, visas, licenses, bank statements) using AES-256-GCM with per-user key derivation. Generates QR codes for offline-ready verification, shareable links with expiry, view limits, and full access logging.

  • AES-256-GCM + Per-User Key Derivation
  • QR Code Generation for Offline Verification
  • Share Links with Expiry & View Limits
  • Cross-Border Document Verification API
  • Full Access Logs & Audit Trail
Learn More

CIXIO File Protection — Enterprise Encryption

End-to-end file encryption suite supporting files up to 2GB+ with hybrid RSA+AES-256-GCM encryption. Features RSA key generation (2048–4096-bit), bulk folder encryption, password-protected files (PBKDF2), expiring files with grace periods, and secure sharing links via web UI and REST API.

  • Hybrid RSA (4096-bit) + AES-256-GCM
  • Files & Folder Bulk Encryption (2GB+ tested)
  • Expiring Files with Grace Periods
  • Secure Sharing Links + Web UI & REST API
  • v2.0.0 — 100% Feature Complete

  • OAuth2 / OIDC / JWT Standard
  • Multi-Factor Authentication (MFA)
  • Centralized User Directory
  • Multi-App Integration SDK
  • Session Control & Security Audit

A scalable barcode generation and scanning system that converts any data — files, text, images, documents — into high-density scannable barcodes with multi-layer splitting (4096+ characters), error correction, 2–3x compression, and blockchain integration for tamper-proof verification.
